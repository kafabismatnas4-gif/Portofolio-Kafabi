# Portofolio 2D Artist & UI/UX Designer

Portofolio web profesional yang dirancang khusus untuk posisi **2D Artist** dan **UI/UX Designer** (fokus pada game 2D).

## Teknologi yang Digunakan
- **Frontend**: HTML5, Modern CSS3, Vanilla JavaScript (ES6+)
- **Backend / API**: Python (Serverless Handler)
- **Deployment**: Vercel

## Skema Desain
- **Background Utama**: Putih (`#ffffff` / `#fafbfc`)
- **Teks / Font**: Hitam (`#111827`)
- **Background Judul Section**: Biru Muda (`#e0f2fe`)

## Cara Menjalankan Secara Lokal (Menggunakan Python)

Jalankan skrip lokal Python:
```bash
python dev.py
```
Buka browser pada: `http://localhost:8000`

## Cara Deploy ke Vercel

1. Pastikan Anda telah menginstal Vercel CLI atau menghubungkan repository ke Dashboard Vercel.
2. Jika menggunakan CLI:
   ```bash
   vercel
   ```
3. Konfigurasi routing telah disiapkan otomatis melalui [`vercel.json`](./vercel.json).
