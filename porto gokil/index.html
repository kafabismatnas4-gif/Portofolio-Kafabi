About Me

Saya adalah mahasiswa D4 Teknologi Game yang berfokus pada peran UI/UX Designer dan 2D Artist, khususnya untuk pengembangan game 2D. Dengan latar belakang pendidikan game technology, saya memadukan pemahaman teknis alur interaksi pemain dengan penciptaan visual antarmuka dan aset grafis game. Perangkat utama yang sering saya gunakan mencakup Canva, IbisPaint X, PixelLab, Photoshop, CorelDRAW, serta Machinations untuk analisis sistem game.

Saya senang memecahkan masalah terkait kejelasan navigasi layar game, keterbacaan elemen HUD (Heads-Up Display), serta konsistensi visual antara lingkungan, karakter, dan antarmuka permainan. Selain desain visual dan UI/UX, saya juga memiliki pemahaman dasar dalam pengelolaan versi menggunakan Git serta manajemen basis data dengan MySQL yang mendukung kolaborasi dalam tim pengembang.
